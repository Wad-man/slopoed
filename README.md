# slopoed

Редактор русского текста для ИИ-агентов. Убирает следы нейросети, не ломая смысл, факты и голос автора.

```
$ python scripts/lint.py черновик.md --genre article
slopoed · чистота 14/100 · НЕ ПРОХОДИТ (порог 88) · жанр: статья, лонгрид, блог · слов: 149, предложений: 16

НАХОДКИ (22 правил)

  [F1] «Не просто X, а Y» · небольшая · ×2
    3: 91  «не просто»
    15: 126  «не просто»
    → Сказать Y прямо. Если X и Y — разные факты, конструкция содержательная и остаётся.
  ...

КАРТА ТЕКСТА                                   текст      человек: 10% · медиана · 90%
  Разброс длин предложений                 0,38         0,33 ·   0,51 ·   0,85   ← ниже нормы
  Средняя длина слова, букв                6,37         5,24 ·   5,86 ·   6,50   ← выше нормы
```

## Зачем ещё один скилл

Русских скиллов против слопа уже больше десятка, и большинство начинается со списка запретов. 169
конструкций из таких списков проверены на открытом корпусе LLMTrace: 5 171 живой русский текст
и 9 317 текстов 30 моделей. Вышло три вещи, из которых следует всё остальное.

1. Часть классических маркеров никого не выдаёт. `Не секрет, что`, `раскрыть потенциал`, `дело не в`
   у людей встречаются чаще, чем у моделей. Общий оборот «не X, а Y» тоже.
2. Маркер зависит от жанра. Длинное тире стоит в 58% живых статей и в 33% машинных. В отзывах
   наоборот: 4% и 29%. Один бан-лист на все случаи штрафует живых авторов.
3. Словарь выгорает, структура остаётся. Запятая после «Однако» в зачине встречается у GPT-3.5 в 14%
   текстов, у o3 её нет вовсе. Ровный, без перепадов, ритм предложений при этом встречается у каждого
   генератора чаще, чем у человека.

Поэтому slopoed построен на четырёх решениях.

- Три слоя, по порядку. Слоп это фактура (нет имён, чисел, случаев), затем конструкция (шаблон
  «вступление, три пункта, вывод») и только потом поверхность (обороты, кальки, канцелярит). Починить
  одну поверхность нельзя: выйдет слоп с другим словарём.
- Только измеренное. В каталог попадают обороты, которые в корпусе встречаются у моделей заметно
  чаще, чем у людей. У оборотов из популярных списков без такого перевеса штрафа нет.
- Линтер с картой текста. Кроме находок он показывает, где текст отошёл от нормы живых текстов
  своего жанра: разброс длин предложений, длина слова, частицы, числа.
- Проверка в обе стороны. Чистовик смотрит свежий читатель: что осталось от слопа и что сломано
  правкой, от выдуманной цифры до «выскобленного» текста без голоса.

## Как проходит правка

1. Линтер: балл «было» и карта текста.
2. Фактура: тест на переносимость, размытые авторитеты, вопросы автору. Фактуры нет во всём тексте:
   скилл останавливается и возвращает вопросы, потому что чистить пустоту бессмысленно.
3. Конструкция: зачин, шаблон, финал, связность абзацев.
4. Поверхность: обороты из каталога, кальки, канцелярит.
5. Ритм: разброс длин, а не длина.
6. Живые приметы: проверить, что при чистке не пропали частицы, скобки, вопросы и короткие фразы.
7. Контроль: линтер со сравнением с исходником и свежий читатель. Два круга, не три.

Четыре правила держат всё: ничего не выдумывать, смысл не менять, живость не впрыскивать, чистое не
трогать.

## Установка

### С агентом

Claude Code, Codex, Cursor и другие агенты со скиллами. Нужен Python 3.9+, зависимостей нет.

```bash
git clone https://github.com/Wad-man/slopoed.git ~/.agents/skills/slopoed
# Claude Code: та же папка в ~/.claude/skills/slopoed
# или через skills CLI:
npx skills add Wad-man/slopoed
```

### Без агента

Содержимое [SKILL.md](SKILL.md) вставляется в чат как инструкцию, линтер запускается руками.

Просьбы, на которые скилл рассчитан: «убери слоп из текста», «перепиши по-человечески, факты не выдумывай»,
«покажи, что выдаёт нейросеть, ничего не переписывая», «напиши пост так, чтобы он не звучал как нейросеть».

## Линтер без скилла

```bash
python scripts/lint.py черновик.md --genre article          # пост: --genre post, документ: --genre formal
python scripts/lint.py чистовик.md --before черновик.md     # чистота «было → стало»
python scripts/lint.py - --json < черновик.md               # текст из stdin, вывод для программы
python scripts/sanitize.py черновик.md --fix > чистый.md    # убрать невидимые символы
```

Код возврата 0: текст прошёл порог, 1: не прошёл, 2: ошибка. Оба скрипта читают файлы только внутри
рабочей папки (для остальных есть флаг `--root`) и ничего не записывают на диск: очищенный текст
`sanitize.py` выдаёт на стандартный вывод.

## Как читать балл

Балл показывает чистоту по правилам, а не вероятность авторства. Веса подобраны на корпусе, а порог 88
выбран так, чтобы живые тексты ошибочно не проходили примерно в одном случае из десяти.

| Порог | Живые тексты не прошли | Машинные не прошли |
|---|---|---|
| 80 | 3,2% | 46,0% |
| 85 | 7,4% | 57,2% |
| 88 (по умолчанию) | 10,3% | 62,7% |
| 90 | 13,7% | 66,6% |

## Честные ограничения

- Это не детектор и не способ обойти детектор. Четыре машинных текста из десяти проходят порог, а каждый
  десятый живой текст его не проходит.
- Линтер не читает смысл. Выдуманную цифру, потерянный довод или ставший плоским текст он не заметит,
  поэтому в скилле есть шаг со свежим читателем.
- Нормы посчитаны на статьях, новостях, справке, отзывах и постах. Тексты созданы моделями 2023 – начала
  2025 года. На 30 текстах моделей поновее, которые линтер не видел, порог не прошли 25. У GPT-5.6
  проходят четыре из шести. Для маркетинга и художественной прозы правила работают как гипотеза.
- Словарь моделей меняется. Пересчитать правила на свежем корпусе: `python tools/calibrate.py test.jsonl`.

Полный отчёт с таблицами лежит в [docs/research.md](docs/research.md).

## Состав

| Файл | Что внутри |
|---|---|
| `SKILL.md` | Семь шагов правки, режимы, непреложные правила |
| `references/patterns.md` | Каталог: следы, сильные и слабые обороты, привычки, не-маркеры, живые приметы |
| `references/craft.md` | Приёмы по слоям: фактура, конструкция, ритм, русский слой, четыре способа испортить |
| `references/genres.md` | Профили поста, статьи, документа и художественного текста |
| `references/review.md` | Бриф свежего читателя: проверка в обе стороны |
| `references/voice.md` | Паспорт голоса: как собрать и как пользоваться |
| `scripts/lint.py`, `scripts/rules.json` | Линтер и его правила без зависимостей |
| `scripts/sanitize.py` | Поиск и уборка невидимых символов (очищенный текст на stdout) |
| `tools/calibrate.py` | Калибровка правил на корпусе |
| `tests/` | 18 тестов: сплиттер, маскировка, правила, фикстуры, пути, очистка |

Проверка после изменения правил: `python tests/test_lint.py`.

## English

slopoed is a Russian-language text editing skill for AI agents. It removes signs of neural-network
writing while preserving meaning, facts and the author's voice. Every rule was measured on LLMTrace
(5,171 human and 9,317 machine Russian texts). At the default threshold the linter fails 63% of machine
texts and 10% of human texts, so it is used as a floor, with a fresh-reader review on top. The research
behind the rules is in [docs/research.md](docs/research.md) (Russian).
